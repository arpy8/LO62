# STL Files  

This directory contains all the **STL (Stereolithography)** files required for the construction and assembly of this project.  
These designs were created using **Fusion 360** and later sliced using **Cura**.  

## Important Note

- The [main frame](./main_frame.stl) that connects the motor to the wheel is lowkey flawed. A lot of modifications were made after the prints arrived.
- Infill rate was set to **100%**
- Printing the [little pulley](./little_pulley.stl) was pointless as it was literally obliterated due to the immense load lmao ([image for reference](../misc/rip_little_pulley.png))
